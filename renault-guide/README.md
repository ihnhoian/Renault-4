# 르노코리아 출고 고객 운행 가이드

르노코리아 전주 동부대로대리점에서 출고한 **그랑 콜레오스 · 필랑트** 고객을 위한 모바일 웹 가이드입니다.

- 라이브: <https://ihnhoian.github.io/Renault-4/renault-guide/>
- 필랑트 탭 바로 열기: `?model=filante` 또는 `#filante`

## 수록 내용

| 구역 | 내용 |
|---|---|
| Section 01 | My Renault 공식 앱 (Google Play / App Store) 설치 안내 |
| Section 02 | 르노코리아 공식 e-Guide 영상 — 그랑 콜레오스 53편, 필랑트 27편 재생목록과 추천 영상 5편 |
| Section 03 | 중립 주차(N단) 6단계 절차와 주의 사항, 차종별 공식 영상 |
| Section 04 | 무선 소프트웨어 업데이트(FOTA) 5단계 순서도 — 자동 다운로드, 알림 확인, 유의사항, 2분 내 도어 잠금 5조건, 최신 버전 확인 + 필수 주의사항과 르노코리아 공식 공지 링크 |
| Section 05 | 담당 지점장(안인회) 연락처, 대리점, 르노코리아 엔젤센터(080-300-3000) · 커넥티비티 고객센터(080-339-3000) |
