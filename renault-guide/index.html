Section 03

중립 주차(N단) 30초 가이드

시동이 켜진 상태에서 시작합니다. 그랑 콜레오스와 필랑트는 동일한 절차를 사용합니다. 순서를 바꾸면 시동이 걸린 채로 남거나 경고음이 계속될 수 있습니다.

  1. 01제어 센터 실행시동이 켜진 상태에서 중앙 디스플레이 좌측 상단을 아래로 스와이프합니다.
  2. 02오토홀드 · 자동 주차 브레이크 끄기제어 센터에서 오토홀드(Auto Hold)와 N에서 자동 작동 주차 브레이크를 OFF로 설정합니다.
  3. 03전자식 파킹 브레이크 해제브레이크를 밟은 상태에서 EPB 레버를 눌러 해제하고, 클러스터 표시등이 꺼진 것을 확인합니다.
  4. 04N(중립)단으로 변속브레이크를 밟은 채 기어를 N단으로 이동합니다.
  5. 05시동 끄기브레이크를 밟은 상태에서 시동을 끕니다. 이때 나오는 경고음과 경고 메시지는 무시합니다.
  6. 06하차 후 이동 여부 확인도어를 잠근 뒤 차량을 가볍게 밀어 이동 여부를 반드시 확인합니다.
주의 경사로·비탈길 중립 주차는 절대 금지 부득이하게 이중주차를 할 때는 앞바퀴를 일자로 정렬합니다. 경사진 곳에서는 반드시 P단과 주차 브레이크를 사용합니다.

Section 04

무선 소프트웨어
업데이트 순서도

그랑 콜레오스와 필랑트는 openR 파노라마 스크린을 쓰는 같은 절차입니다. 차량이 업데이트를 내려받으면 중앙 스크린 안내에 따라 아래 5단계만 진행하면 되고, 서비스 센터를 방문할 필요가 없습니다.

5단계 화면 안내 순서 2분 설치 시작 조건 10분~1시간 예상 소요 무상 진행
  1. STEP 01 주행 중 자동 수신
    자동 다운로드 (주행 중) 별도 조작 없이 차량이 무선 통신으로 업데이트 파일을 자동으로 내려받습니다. 다운로드가 끝난 뒤 기어 P단 · 시동 OFF 상태가 되면 중앙 스크린에 안내 팝업이 뜨고, 팝업에서 업데이트 예약을 선택해 원하는 일시에 진행할 수도 있습니다.
    상태 주행 중 자동 수신 → 시동 OFF · P단 → 안내 팝업 표시
  2. STEP 02 알림 확인
    알림 확인 후 '지금 업데이트' 선택 시동이 꺼진 상태에서 중앙 스크린의 <업데이트 알림> 팝업 하단에 있는 '지금 업데이트' 버튼을 터치합니다.
    화면 <업데이트 알림> → 지금 업데이트
  3. STEP 03 유의사항 확인
    유의사항 확인 후 한 번 더 선택 예상 소요 시간과 업데이트 중에는 차량을 사용할 수 없다는 안내를 확인한 뒤 '지금 업데이트'를 한 번 더 누릅니다. 예상 시간은 업데이트 내용에 따라 다르며, 최근 공지 기준 그랑 콜레오스 약 10분 · 필랑트 약 1시간 내외입니다.
    화면 <유의사항 안내> → 지금 업데이트
    진행 전 준비 소지품을 모두 챙겨 하차 · 휴대폰 Wi-Fi·블루투스 연결 해제 · 블랙박스 전원 분리 · OBD 단자 외부 장착물 제거
  4. STEP 04 핵심 단계
    전원 하차 후 2분 내 모든 도어 잠금 카운트다운 화면이 뜨면 모든 탑승자가 내린 뒤 차량의 모든 도어를 잠급니다. 시작 후 2분 이내에 아래 5가지 조건이 모두 충족되어야 설치가 시작됩니다.
    화면 <업데이트 시작> 2분 카운트다운 → 하차 후 도어 잠금
    2분 이내 설치 시작 조건 5가지
    • ①시동 정지OFF
    • ②기어 P주차
    • ③모든 도어 잠금전 좌석 포함
    • ④디스플레이 조작 금지중앙 · 동승석
    • ⑤12V 배터리충전 양호

    2분 이내에 중앙 스크린이나 동승석 디스플레이를 조작하면 업데이트가 취소됩니다.

  5. STEP 05 자동 설치
    자동 설치 후 최신 버전 확인 설치가 끝나면 시스템이 자동으로 종료됩니다. 다음 시동 후 중앙 스크린 설정에서 '새로운 버전 알림' 문구가 '최신 버전'으로 바뀌었는지 확인합니다. 일부 개인 설정이 초기화될 수 있으니 필요하면 다시 설정합니다.
    화면 자동 종료 → 설정 · 새로운 버전 알림 → 최신 버전
주의 어린이 · 반려동물을 차 안에 혼자 두고 진행하지 마십시오 설치가 시작되면 완료될 때까지 차량을 사용할 수 없습니다. 아래 내용을 확인한 뒤 진행하십시오.
  • 설치 중 사용 불가도어 개방, 차량 주행, 멀티미디어 사용이 불가합니다.
  • 스마트키로 도어 열림 불가업데이트 중에는 스마트키로 도어를 열 수 없습니다. 긴급하면 비상키나 내부 도어핸들로 열 수 있으나 업데이트가 중단됩니다. 중단되더라도 이후 다시 실행할 수 있습니다.
  • 설정 초기화업데이트 후 일부 설정 값이 초기화될 수 있으니 필요한 기능은 다시 설정하십시오.
